# IPT · Agendamento de aulas (demo)

Web app de agendamento de aulas para o Instituto Performance Total.

- `index.html`: app do aluno (cadastro, agenda com vagas, reserva, minhas reservas)
- `admin.html`: painel do Instituto (aulas do dia, presença, alunos, indicadores, ajustes)

Banco de dados: projeto "IPT Agendamento Demo" (dados fictícios).
Senha do painel na demo: `ipt2026`.
